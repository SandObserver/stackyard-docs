## Configuration

| Field | What it does | Required |
| --- | --- | --- |
| Style | Digital or Analog. | Yes |
| Theme | Dark or Light card. | Yes |
| Timezone | An IANA timezone name, for example `America/Toronto`. Leave blank for the browser's local time. | No |
| Show date | Shows the weekday and date under the time. | No |
