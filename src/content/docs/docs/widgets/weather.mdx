## Picking a location

Type a city into Search, press Fetch, then pick the matching place from the list. Choosing a place stores its coordinates with the widget.

## Configuration

| Field | What it does | Required |
| --- | --- | --- |
| Search | A city name to look up. Not stored. | No |
| Location | The place picked from the search results. | Yes |
| Units | Celsius or Fahrenheit. Defaults to Celsius. | Yes |
| Show feels like | Adds the apparent temperature. Off by default. | No |
| Link URL | Where clicking the widget opens. | No |
