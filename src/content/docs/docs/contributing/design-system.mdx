Stackyard follows Apple's [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines) for type, spacing, controls and motion. This page covers only what is specific to Stackyard. Tokens live in `ui/css/tokens.css`.

## Color

Teal is the brand accent. Rules name a role below, never a raw color.

<ThemePanels />

The other hues and grays are Apple's system colors.

## What differs

<div class="sy-gut__body">

- **Both pages carry both themes.** **Display Mode** sets the theme on `<html>`, and the dashboard, the Settings pages and every widget follow it.
- **Text on cards uses `--sy-a11y-dim`.** Apple's secondary label colors fail WCAG contrast on Stackyard's cards.
- **Text on a user-picked tile color is black or white,** whichever contrasts more. It is measured, never fixed.
- **Widgets cannot read tokens.** A widget copies the values it needs from the palette.

## Icons

<div class="sy-gut__body">

The interface draws one icon set, defined in [`ui/js/icon-set.js`](https://github.com/SandObserver/stackyard/blob/main/ui/js/icon-set.js). This list is built from that file, so it always matches the app.

<IconSet />

Each icon is a short list of shapes on a 24-unit grid. The file turns the list into an SVG sprite. Icons follow the text color, and one part per icon takes the accent.

</div>
</section>

<section class="sy-gut">

## Icon rules

<div class="sy-gut__body">

<dl class="sy-kv">
  <dt>Grid</dt><dd>24 by 24. Draw inside 2 to 22.</dd>
  <dt>Coordinates</dt><dd>Whole numbers on every straight edge.</dd>
  <dt>Stroke and gap</dt><dd>2 and 2.</dd>
  <dt>Corners</dt><dd>4 for shapes 14 or larger, 3 medium, 2 small.</dd>
  <dt>Bars and dots</dt><dd>Bars 2 high, rows every 4. Dots radius 2, nodes radius 3.</dd>
  <dt>Accent</dt><dd>At most one part: the thing the icon is about.</dd>
</dl>

</div>

## Add an icon

<div class="sy-gut__body">

1. Add an entry to `ICONS` in `ui/js/icon-set.js`. Draw what the widget shows, in as few shapes as read at 16 pixels.

   ```js
   system: {
     shapes: [
       line('M3 16l5-5 4 4 5-5'),      // the graph
       dot(19, 6, 3, 'accent'),         // the latest reading
     ],
   },
   ```

2. Map a glyph name to it in `ui/js/widget-glyphs.js`, and add the same name to `VALID_GLYPHS` in `api/src/widgets.js`.
3. Set `"glyph"` in the widget's `widget.json`. See [List icon](/docs/create-a-widget/manifest/#list-icon).

`rect`, `circle` and `shape` draw bodies. `frame` draws a hollow container. `detail`, `dot` and `bar` draw small parts. `line` and `ring` draw lines. A part that holds something is a frame with solid contents. An action or state is a line. The one accent part sits on open background. A test rejects a glyph that points at no icon.
