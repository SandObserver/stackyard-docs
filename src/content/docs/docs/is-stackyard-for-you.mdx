## Choose Stackyard if

- You want a launcher that flags an unhealthy app.
- You set things up in a web UI, not a YAML file.
- You check the dashboard many times a day.
- You want a value from any API on a tile, with no code.
- You want [WCAG 2.2 AA](/docs/accessibility/), a home-screen app and six languages.

</section>
<section>

## Choose another if

- You want history or alerts. Stackyard shows current values only.
- You want configuration as code in a Git repository.
- You need user accounts. Stackyard has [one admin password](/docs/security/).
- You want plugins. The widget set is fixed.

</section>
