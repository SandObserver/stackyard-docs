---
title: Dashboard switch widget
description: Link separate Stackyard dashboards, one per room or per site, as a keyring on the grid.
---

import WidgetGroup from '../../../../components/WidgetGroup.astro';
import SettingList from '../../../../components/SettingList.astro';

A launcher for other dashboards, drawn as hanging keys. Use it to move between instances, for example one dashboard per room or per site. It renders in the browser and makes no network request.

<WidgetGroup caption="Two keys is the limit at small, five at medium."
  items={[
    { type: 'dashboard-switch', file: 'index.html', id: 'demo-dashswitch',    card: 'dark', title: 'Dashboard switch, small',  label: 'Small' },
    { type: 'dashboard-switch', file: 'index.html', id: 'demo-dashswitch-md', size: 'medium', card: 'dark', title: 'Dashboard switch, medium', label: 'Medium' },
  ]} />

Small holds two keychains. Medium holds five.

<SettingList title="Settings for each keychain" items={[
  { name: 'Name', text: 'The label on the key, for example `Living Room`.', optional: true },
  { name: 'Dashboard URL', text: 'Where the key opens.' },
  { name: 'Fob colour', text: 'Auto derives the colour from the URL. Or pick Teal, Cyan, Orange, Pink, Purple, Green, Yellow or Blue.', optional: true },
]} />

<SettingList title="Settings" items={[
  { name: 'Open in', text: 'Same tab or new tab. Defaults to same tab.' },
]} />

:::note
Stackyard has no user accounts. This widget links separate instances. It does not switch users.
:::
